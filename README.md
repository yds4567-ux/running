# 러닝 마일리지 트래커

지인 6명이 함께한 8월 러닝 대회의 기록을 실시간으로 모아 보고, 핸디캡을 반영한 순위를 보여주는 웹사이트입니다.

**사이트**: https://yds4567-ux.github.io/running/

## 만든 이유

러닝 대회를 하면서 누가 몇 km를 뛰었는지 매번 단톡방에서 물어보고 직접 더해야 했습니다.
각자 뛴 기록을 바로 남기고, 모두가 같은 순위를 실시간으로 볼 수 있으면 편하겠다고 생각해 직접 만들었습니다.

## 주요 기능

- **기록하기**: 이름·날짜·거리(km)를 입력하면 바로 저장
- **대결 현황**: 팀별 누적 거리를 막대그래프로 비교
- **핸디캡 순위**: 실력 차이를 맞추기 위해 팀별 배율(1.7배, 1.8배)을 곱한 환산 거리로 순위 계산
- **최근 기록**: 최근 30개 기록 표시, 잘못 입력한 기록 삭제
- **실시간 반영**: 다른 사람이 기록하면 새로고침 없이 바로 화면에 반영

## 구현 포인트

### 실시간 반영이 끊길 때를 대비한 이중 처리

Supabase Realtime으로 `entries` 테이블이 바뀔 때마다 화면을 다시 그리도록 했습니다.
다만 실시간 연결이 가끔 끊기거나 설정이 안 되어 있으면 기록이 반영되지 않는 문제가 있어서,

- **10초마다** 데이터를 다시 불러오고
- 다른 앱을 보다가 **탭으로 돌아오는 순간** 한 번 더 불러오도록

보완했습니다. 실시간 연결이 실패해도 늦어도 10초 안에는 최신 기록이 보입니다.

## 개선하고 싶은 점

- 지금은 로그인 없이 누구나 기록을 입력·삭제할 수 있어서, 본인 기록만 수정·삭제할 수 있도록 인증과 권한 처리를 추가하고 싶습니다.
- 참가자와 팀 배율이 코드에 직접 들어가 있어, 다음 대회에서도 쓸 수 있도록 설정 화면으로 분리하고 싶습니다.
